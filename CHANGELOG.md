## [1.0.0]

First release.

- Opens KDBX 4.0 and 4.1 vaults
- Password, key file and fingerprint unlock
- Search, view and copy entries; copied values clear after 30 seconds
- Add, edit and delete entries
- Saves to the same file and checks the file before and after each save
- Encrypted backups on the phone
- No internet permission
